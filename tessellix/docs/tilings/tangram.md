# Tangram

`tangram` · family [Nonperiodic](../families/reptiles.md) (`reptiles`)

the classic five-prototile dissection (S M L Q P, u²-areas 1/2/4/2/2) as an area-conserving λ=√2 substitution S→{M}; M→{L}; L→{M,Q,P,S,S}; Q→{M,S,S}; P→{M,S,S}; det=2 two-S seed (all-5-prototile seed negative for det ≤ 40, first L at g=4, all five prototiles at g=5); exact Z[√2] u-pair arithmetic end to end; homochiral P+ (every substitution row rotation-only, so the P− mirror class is unreachable from the seed); non-edge-to-edge (T-junctions 0,0,0,6,10,18 over g=0..5); limit-periodic on the √2^(g+1) block lattice (M142)
