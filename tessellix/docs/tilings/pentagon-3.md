# Pentagon type 3 (Reinhardt)

`pentagon-3` · family [Pentagon Types](../families/pentagons.md) (`pentagons`) · wallpaper group `p2` · oblique lattice

pentagonal (Reinhardt 1918 family 3): A = B = C = D = 120°, E = 60°, a = b = 2, c = 1, d = 4, e = 3 (a = b, d = c + e), exact Q(√3); 1-isohedral, 2 tiles per oblique cell, non-edge-to-edge (every d-side is split at its exact midpoint between two length-2 sides); chiral prototile, one chirality used — the classical three-tile type-3 pinwheel admits no periodic cell for this member
