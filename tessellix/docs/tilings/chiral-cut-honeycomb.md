# Chiral-cut honeycomb

`chiral-cut-honeycomb` · family [Wallpaper](../families/pavers.md) (`pavers`) · wallpaper group `p3` · hexagonal lattice

paver tiling: a side-2 hexagon (area 6√3 = det Λ) cut by a chiral three-armed Y from the alternating vertices to the centre, each arm bending once (Wk = mid(Vk,O) + rotated delta, delta = (−1/8,−1/10) defined once and rotating with the arm), per hexagonal cell ⟨(2√3,0),(√3,3)⟩ (det 6√3): three tiles, one chiral congruence class (all seed 0); edge-to-edge (450 interior edges, 0 T-junctions); the catalog's first p3 realizer — 120°/240° rotations about three 3-fold centre orbits (hex centres, even corners, odd corners — the "333" fingerprint) plus translations only, no 60°/180°/300° rotations, no mirrors (M83, HX-STUDY handoff)
