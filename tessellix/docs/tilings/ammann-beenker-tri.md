# Ammann-Beenker rhomb-triangle

`ammann-beenker-tri` · family [Quasiperiodic](../families/quasiperiodic.md) (`quasiperiodic`)

quasiperiodic rhomb-triangle variant of the A5 tiling: the half-square triangles kept as their own tile class (3 prototiles: square, 45°-rhombus, half-square triangle); local 8-fold symmetry (M129)
