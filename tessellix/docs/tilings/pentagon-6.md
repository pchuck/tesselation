# Pentagon type 6 (Kershner)

`pentagon-6` · family [Pentagon Types](../families/pentagons.md) (`pentagons`) · wallpaper group `p2` · oblique lattice

pentagonal (Kershner 1968): A = B = D = E = 120°, C = 60°, a = d = e = 1, b = c = 2 (A = 2C, C + E = 180°); the unique 30°-grid member, exact Q(√3); achiral prototile (congruent to the floret-pentagonal tile), 2-isohedral, 4 tiles per oblique cell, edge-to-edge (every side paired with exactly one full reverse partner, 10 side-pair orbits)
