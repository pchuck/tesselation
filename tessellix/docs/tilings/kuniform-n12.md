# 2-uniform (3².6²; 3⁴.6)

`kuniform-n12` · family [Two-Uniform](../families/kuniform.md) (`kuniform`) · wallpaper group `cmm` · centered lattice

2-uniform k-uniform: rows of edge-sharing hexagons with unit-triangle bands between the rows, the two-uniform family's first cmm entry (Wikipedia `2-uniform n12`, t = 2, e = 4); centered rectangular basis ⟨(√3, 0), (√3/2, 5/2)⟩ with the centering vector as basis, det 5√3/2 (right-handed); 5 tiles/cell (1 hexagon + 4 triangles, the 2-hexagon + 8-triangle centered cell is S ⊎ (S + c)); both vertex orbits 2 translation classes per cell (M97)
