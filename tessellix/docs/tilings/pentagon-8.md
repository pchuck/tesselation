# Pentagon type 8 (Kershner)

`pentagon-8` · family [Pentagon Types](../families/pentagons.md) (`pentagons`) · wallpaper group `pgg` · rectangular lattice

pentagonal (Kershner 1968): B = C = 120°, tan A = 3√3 (A ≈ 79.11°), cos D = 1/7 (D ≈ 81.79°), tan E = −√3/2 (E ≈ 139.11°), A = E − 60°, a = 6√7, b = c = d = e = 14; 2-isohedral, 8 tiles (four direct, four mirror) per rectangular cell, edge-to-edge, two perpendicular glide families squaring to w1 and −w2
